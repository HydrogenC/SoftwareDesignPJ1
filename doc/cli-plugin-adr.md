# CLI 插件框架 ADR

## 1. 属性处理、冲突和撤销

`handles` 和 `apply` 看到的是冻结的 `ShapeView`，可按 `kind` 判断图形类型并查看子部件的 ID。处理器通过 `AttributeWriter.set` 修改目标及其后代的属性。单次处理调用结束后关闭写入器。处理器按注册顺序判断，零命中交给图形的属性白名单，多命中时报出所有命中者并拒绝修改。

写入器记录每次更新的节点 ID、属性和前后值。成功的 `set` 作为一条命令进入历史栈。异常时按逆序恢复已经完成的更新，命令历史在成功返回之后才更新。撤销逆序恢复，重做顺序重放。两者按 ID 定位当前图形，重做已经撤销的创建命令可能产生新实例。图形属性方法须支持用旧值恢复，并在拒绝某个值时保持该属性原状。

## 2. 特殊图形读回与结构不变量

`ShapeFactory.forSvg` 优先选择名称与 `data-kind` 相同且支持当前 SVG 标签的 provider，缺省查找名称和标签相同的 provider。`SvgReader` 先收集显式 ID 并拒绝重复，再按源码顺序为未命名节点分配可用 ID。provider 收到已构造的直接子节点，可检查必要部件，然后返回尚未挂入文档的空图形。读入器统一挂载子节点并建立索引，读入成功后才替换当前文档。

容器用 `assertCanUngroup` 和 `assertCanRemove` 表达自身约束。换父和删除在修改前询问原父容器，批量分组和解组在修改结构前先检查涉及的全部节点。同父换序保留子节点归属。新增子树在挂载前检查其内部及与当前文档间的 ID 冲突。

`BoxProvider` 通过公开的 `ShapeCreationContext.create` 构造 `<id>-rect` 和 `<id>-label`，由 `Document.add` 一次检查整棵新增子树。`Box` 保存为 `<g data-kind="box">`。加载插件时，读回要求两个派生 ID 对应类型正确的直接子节点。缺失、错类型或嵌套位置错误会拒绝整次读入，现有文档和历史保留。没有加载插件时，普通 `g` provider 接管并保留其可识别的 SVG 子节点。重复 ID 在分派 provider 前拒绝，两种装配的结果一致。

`Box` 允许额外子节点和嵌套。两个必要部件不能直接删除或换父，支持同父换序。插件按派生 ID 定位部件，因此换序后仍可设置属性和读回。整棵 `box` 子树仍可整体移动、加入分组或删除。`BoxAttributes` 只处理 `fill` 和 `label`，分别通过写入器修改矩形的 `fill` 与文字的 `text`。从 SVG 读回时矩形可能通过父组继承颜色，撤销设置会恢复原来的缺省属性。

## 3. 注册事务和清单校验

代码装配与配置装配均调用 `PluginHost.load`。组合根供应对象实例，配置加载器完成模块路径解析和默认导出获取。加载器会整体验证配置，再按数组顺序解析条目。`enabled: false` 的条目跳过导入。

宿主先验证 `package.json` 声明结构，把 `activate(ctx, options)` 中的注册放到临时表里，然后比较声明和实际的分类与名称集合。清单顺序不影响比较，实际注册顺序决定帮助文案和标签追加顺序。重复注册、激活异常和清单不符均丢弃当前插件的全部暂存注册。解析顶层模块与实际求值分开，缺少传递依赖或模块求值出错时报告激活失败。后续条目继续加载。

## 4. 未保存标记与祖先传播

`modified-star` 按内容与最近一次成功 `save` 或 `read` 时的状态是否一致判断 dirty。插件实例按 ID 保存基准快照，渲染时比较节点类型、SVG 标签、属性键值、文本和有序子节点。属性的枚举顺序可变化。撤销若恢复了基准内容，`*` 消失，重做若再次改变内容，`*` 恢复。成功 `save` 或 `read` 会建立新基准，读写失败时继续使用原基准。`init` 清空基准，因此新画布立即标星。新建节点只要在基准中没有相同内容，也立即标星。

子节点的内容变化向上传播，所有祖先容器直到画布根都会标星。新增、删除、换父和换序改变父容器的有序子节点列表。换父时，如果既有图形的子树内容本身相同，它自己的行保持原状态，原父容器、新父容器以及它们的祖先反映变化。被删掉的行通过仍可见的祖先反映变化。

插件在实例字段中维护基准快照和以不可变 `ShapeView` 为键的缓存。同次树渲染中的容器和子行共享这些视图，使祖先和子行可以复用比较结果。`tree <id>` 使用同一个基准索引比较子树。

标签按注册顺序用一个空格追加到行尾。默认装配先注册 `box-type-label`，再注册 `modified-star`，同一行显示为 `g#n1 (box) *`。两者各自读取 `ShapeView`。
